# ADR-0002: Apache License 2.0

- Status: Accepted
- Date: 2026-08-10
- Scope: UniVector

## Decision

UniVector is distributed under Apache-2.0. The repository ships `LICENSE`,
`NOTICE`, and `CONTRIBUTING.md`; source files carry SPDX identifiers and every
commit carries a DCO sign-off.

The license covers the original UniVector implementation. Dependencies retain
their own licenses and are not copied into this repository, except that the
Python source distribution vendors UniVector's own Nim sources and manifest.
